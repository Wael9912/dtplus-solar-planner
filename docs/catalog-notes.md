## 3. Design caveats the sizing tool must encode
1. **Voc at cold temperature**: Voc_cold = Voc x (1 + tcVoc x (Tmin - 25)). Khartoum Tmin ~ 10 °C → +3.75% for TOPCon; Gulf desert nights can hit 0-5 °C → +5-6%. Check N_series x Voc_cold < inverter max PV voltage.
2. **Vmp at hot temperature**: Vmp_hot = Vmp x (1 + tcPmax x (Tcell - 25)) with Tcell ≈ ambient + 25-30 °C → at 45 °C ambient, Tcell ≈ 70-75 °C → Vmp drops ~13-15%. Check N_series x Vmp_hot > MPPT min (and ideally > full-load MPPT min, e.g. Deye 300-350 V).
3. **Isc per MPPT**: 210 mm modules (650-725 W) have Isc 17-18.5 A; one string per 13-16 A MPPT input is not allowed, one string per 26-32 A input is fine; two strings in parallel need ≥ 36 A inputs.
4. **Battery current**: inverter max charge/discharge A vs sum of battery module max A (e.g. 12 kW Deye at 240 A needs ≥ 3 x 100 A modules); keep modules ≥ 0.5C total.
5. **Lead-acid**: usable 50% DoD, charge ≤ 0.2C, ventilation; LiFePO4 90-95% DoD.
6. **Ambient derating**: inverters (Victron 4,000 W@25 °C → 3,000 W@65 °C; Deye derates above 45 °C), cables (see above), batteries (LiFePO4 charge 0-50/55 °C only).
7. **DC/AC ratio**: use the inverter's maxPvInputKw field, not a global ratio; Growatt SPF is 1.2x, Deye 1.3x, string inverters 1.5x.
8. **Temperature coefficient of warranty**: most Tier-1 give 12-15 y product / 25-30 y power (TOPCon 87.4% at year 30, 0.4%/yr).
